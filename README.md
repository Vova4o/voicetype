# voicetype — Енот

Локальный голосовой ввод на Go для **macOS с Apple Silicon**. Говорите по-русски — программа распознаёт речь через **GigaAM v3 с пунктуацией** и вставляет текст в активное поле любого приложения через буфер обмена и ⌘V.

**«Енот текст»** включает диктовку, **«Енот стоп»** выключает. Переключать ввод можно и мышью через индикатор в строке меню.

## Как пользоваться

1. Запустите программу и дождитесь надписи **«Енот: ожидание»** в строке меню.
2. Щёлкните в поле, куда нужно вводить текст.
3. Скажите **«Енот текст»**, сделайте короткую паузу и диктуйте.
4. Скажите **«Енот стоп»**, чтобы выключить вставку.

Можно произнести команду и текст в одной фразе. Сами команды в поле не вставляются. Enter программа не нажимает.

### Индикатор в строке меню

| Надпись | Состояние |
| --- | --- |
| **Загрузка…** | Подготовка файлов и загрузка модели |
| **ожидание** | Микрофон слушается, вставка выключена |
| **ВКЛ** | Диктовка включена |
| **Ошибка** | Подробности доступны в меню индикатора |

Нажмите индикатор → **«Включить диктовку»** или **«Остановить диктовку»**, если голосовая команда не сработала. Пункт **«Услышано»** показывает последние распознанные слова: можно увидеть, как модель поняла команду.

### Задержка

GigaAM в этой программе обрабатывает законченные фразы. После **700 мс тишины** начинается распознавание, затем вставляется готовый текст. Промежуточного вывода слов нет; время вычислений добавляется к ожиданию паузы.

Микрофон читается отдельно от распознавания. Очередь ограничена 60 секундами звука; при переполнении программа сообщает об ошибке. Непрерывная фраза принудительно разделяется примерно через 20 секунд.

## Требования

- macOS на Apple Silicon (`arm64`); другие платформы не проверены.
- Go **1.25 или новее**, включённый cgo.
- Xcode Command Line Tools с C/Objective-C компилятором и SDK macOS.
- `ffmpeg` в `PATH`.
- `sherpa-onnx` **1.13.8** для macOS arm64: библиотеки `libsherpa-onnx-c-api.dylib` и `libonnxruntime.dylib` рядом друг с другом.
- Разрешения macOS на микрофон и «Универсальный доступ» для вставки текста.

Распознавание выполняется на CPU. Python для запуска не нужен.

## Установка и сборка

### 1. Подготовьте зависимости

Если Command Line Tools ещё не установлены:

```sh
xcode-select --install
```

Если используете Homebrew, `ffmpeg` можно установить так:

```sh
brew install ffmpeg
```

Библиотеки распознавания можно получить из npm-пакетов sherpa-onnx. Для этого шага нужны Node.js и npm; во время работы программы они не используются:

```sh
npm install --prefix "$HOME/.local/share/voicetype/runtime" --no-save \
  sherpa-onnx-node@1.13.8 sherpa-onnx-darwin-arm64@1.13.8
```

Если уже установлена Maracuya с голосовым рантаймом, программа может автоматически найти библиотеки в `~/.maracuya/service/voice/runtime/`. Сама Maracuya для работы voicetype не требуется.

### 2. Соберите приложение

```sh
git clone https://github.com/Vova4o/voicetype.git
cd voicetype
./build.sh
```

Скрипт создаёт исполняемый файл `voicetype`, копирует его в `Voicetype.app` и подписывает приложение локальной подписью. Готового нотарифицированного установщика в репозитории нет.

На машине разработки SDK 27 несовместим с установленным линкером, поэтому скрипт выбирает SDK 26.5, если он доступен. Свой SDK можно указать явно:

```sh
SDKROOT="$(xcrun --show-sdk-path)" ./build.sh
```

### 3. Запустите

Для библиотек, установленных через npm по инструкции выше:

```sh
./Voicetype.app/Contents/MacOS/voicetype \
  -library "$HOME/.local/share/voicetype/runtime/node_modules/sherpa-onnx-darwin-arm64/libsherpa-onnx-c-api.dylib"
```

Если библиотеки автоматически находятся в рантайме Maracuya:

```sh
./Voicetype.app/Contents/MacOS/voicetype
```

При первом запуске программа проверяет модель в `~/.local/share/voicetype/gigaam-v3-ru/`. Недостающие или повреждённые файлы скачиваются автоматически с Hugging Face. Проверяются размер и SHA-256. После загрузки модели распознавание работает без интернета.

### 4. Разрешите доступ в macOS

В **«Системные настройки → Конфиденциальность и безопасность»**:

- разрешите доступ к **микрофону** для приложения или терминала, которому macOS показывает запрос;
- в **«Универсальном доступе»** добавьте собранное `Voicetype.app` и включите переключатель.

После пересборки macOS может перестать признавать прежнее разрешение. Если появилась ошибка вставки, удалите приложение из списка «Универсального доступа», добавьте текущую сборку заново и перезапустите программу.

## Автозапуск при входе

`com.voicetype.plist` — шаблон LaunchAgent. Команда ниже подставляет пути текущей машины и сохраняет готовый файл в `~/Library/LaunchAgents/`:

```sh
python3 - <<'PY'
from pathlib import Path
import plistlib

project = Path.cwd()
home = Path.home()
library = home / '.local/share/voicetype/runtime/node_modules/sherpa-onnx-darwin-arm64/libsherpa-onnx-c-api.dylib'
if not library.is_file():
    raise SystemExit(f'Не найдена библиотека: {library}; укажите её путь в переменной library')
text = (project / 'com.voicetype.plist').read_text()
config = plistlib.loads(text.encode())
config['ProgramArguments'] = [str(project / 'Voicetype.app/Contents/MacOS/voicetype'), '-library', str(library)]
config['WorkingDirectory'] = str(project)
config['StandardErrorPath'] = str(home / 'Library/Logs/voicetype.log')
destination = home / 'Library/LaunchAgents/com.voicetype.plist'
destination.parent.mkdir(parents=True, exist_ok=True)
(home / 'Library/Logs').mkdir(parents=True, exist_ok=True)
destination.write_bytes(plistlib.dumps(config))
PY
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/com.voicetype.plist"
```

Перед включением автозапуска завершите экземпляр, запущенный вручную, с помощью `Ctrl+C`, чтобы микрофон слушала одна копия программы.

Перезапустить службу:

```sh
launchctl kickstart -k "gui/$(id -u)/com.voicetype"
```

Остановить фоновую службу:

```sh
launchctl bootout "gui/$(id -u)/com.voicetype"
```

При следующем входе она снова запустится, пока файл остаётся в `~/Library/LaunchAgents/`. Чтобы убрать автозапуск, после остановки переместите этот файл из каталога LaunchAgents.

## Параметры

| Флаг | Назначение | По умолчанию |
| --- | --- | --- |
| `-model-dir` | Каталог GigaAM v3 | `~/.local/share/voicetype/gigaam-v3-ru` |
| `-library` | Путь к `libsherpa-onnx-c-api.dylib` | Поиск в рантайме Maracuya |
| `-device` | Устройство ввода ffmpeg | `:default`, системный микрофон |
| `-threads` | Число потоков распознавания | `2` |
| `-stdout` | Вывод в терминал вместо вставки, без индикатора | Выключен |

В режиме `-stdout` команды «Енот текст» / «Енот стоп» тоже действуют.

Список устройств:

```sh
ffmpeg -f avfoundation -list_devices true -i ""
```

## Если что-то не работает

- **Команда не включает ввод:** откройте индикатор, проверьте «Услышано» и включите диктовку мышью.
- **Текст распознаётся, но не вставляется:** проверьте «Универсальный доступ» для текущего приложения. При ошибке отправки ⌘V текст остаётся в буфере — его можно вставить вручную.
- **Долго нет текста:** сделайте паузу; фоновый шум может мешать определению конца фразы.
- **Не найден sherpa-onnx:** передайте путь к библиотеке через `-library`.

Лог фоновой службы: `~/Library/Logs/voicetype.log`. В него записываются состояния и ошибки, без распознанных фраз. Последняя фраза в меню хранится только в памяти, максимум 80 символов. Для вставки программа заменяет содержимое системного буфера обмена.

## Проверки

```sh
go test -race -count=1 ./...
go vet ./...
```

Если нужен определённый SDK, добавьте к командам `SDKROOT=/путь/к/SDK`.

В проекте проверяются разделение фраз, голосовые команды, переключение состояния, UTF-8 в буфере обмена, чтение аудио и отмена захвата. Работа микрофона и вставка в другое приложение требуют отдельной проверки на macOS.

## Используемые проекты

- [GigaAM](https://github.com/salute-developers/GigaAM) — модель распознавания русской речи.
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — выполнение ONNX-моделей; в репозитории находится заголовок C API. Его лицензия сохранена в [third_party/sherpa-onnx-LICENSE](third_party/sherpa-onnx-LICENSE).
- [FFmpeg](https://ffmpeg.org/) — захват микрофона.

Файлы моделей и библиотеки рантайма в репозиторий не включены.
